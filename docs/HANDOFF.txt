9. PITFALLS WE ALREADY HIT (do not repeat)
======================================================================================================================
 - Weak phone GPU (Adreno 610): never repaint full screen gradients every frame; cache layers. Intro and cards keep paint work small.
 - Robolectric and Compose tests hang with infinite animations: use finite animations only (ScrollCue plays three bounces then rests).
 - LayoutAuditTest fails if any text is cut off or ellipsised: stack buttons vertically when LocalDensity.fontScale is above 1.15; avoid maxLines with ellipsis on titles.
 - A shader fill takes the transparency of the paint colour set before it: set paint.color to an opaque colour before using a shader (DashboardArt).
 - Coroutines started from a composable are cancelled when it leaves composition (sign in screen): finish important work in NonCancellable.
 - Typing "ctrl+a" through browser automation can insert the letter a: avoid it when editing store text.
 - Source files mix CRLF and LF line endings: edit with tools that preserve them (the Edit tool is fine; in Python use newline='').
 - Release build must keep INTERNET only because of sharing; the privacy page, terms and release gate must stay in step with the manifest and the app texts.
 - Kotlin edits: check imports (hygiene.py lists unused ones); Settings.kt needs the sp import for AppName calls.
 - The word "just", exclamation marks, trailing dots and em dashes fail the checks.
